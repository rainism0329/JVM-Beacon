1. Open JVM Beacon

Install the plugin from the IDE's Plugins page and restart when prompted. Open a project, then choose View → Tool Windows → JVM Beacon.

2. Choose a target

Click Connect JVM…. For a local application, select its Java process or enter its PID. If it has no local management endpoint, explicitly allow starting the local management agent. This changes the target's management state; only inspect applications you are authorized to access.

For remote JMX, enter server.example:9010, an IPv6 endpoint such as [::1]:9010, or a full JMX/RMI service URL. Enter credentials if required. The registry and the advertised RMI connector host/port must both be reachable. TLS settings and trusted certificates must match the server; the plugin does not downgrade security automatically.

3. Start a live signal

After connecting, check the target identity and start time. The initial connection takes one sample. On Telemetry, choose Start live trend or enable Auto · 2 s. Selecting a metric alone does not start sampling. JVM uptime is a useful first signal on an idle target.

4. Inspect an MBean or a thread

In MBeans, search for an object and select it. Choose an attribute, then Read value or press Enter. Use Explore… for supported structured results. Browsing definitions does not read every getter.

To invoke an exposed method, turn off Read-only, open Operations, select the exact signature, enter supported parameters, and confirm the target. Do not repeat a timed-out operation without checking whether it already executed.

On Threads, use Capture threads to read platform-thread stacks. Filter the captured rows, inspect Lock chains, or pin a baseline for a later comparison.

5. Preserve or explore the evidence

Use Snapshots → Save snapshot… to save collected metrics, optional platform threads and your notes. Add a tab with the tool-window + or Alt+Insert, then reopen the capture there for offline reading.

For an existing recording, choose Flight Recorder → Open local .jfr…. A live JFR capture starts with Check / refresh and an explicitly confirmed bounded recording. Download it after it reaches STOPPED.

If a trend looks frozen: confirm Auto is enabled, the connection tab is visible, and sample timestamps are advancing. A flat value can be real; a gap is not recovered history. STALE means the connection ended and the retained data is older evidence. The visible error category and connection stage help identify the next step.
