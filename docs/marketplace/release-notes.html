1.0.0-rc.3

Broader IntelliJ IDEA compatibility for the first JVM Beacon release candidate.

  • Lowered the minimum supported platform to IntelliJ IDEA 2024.2 (build 242) and removed the fixed upper IDE build limit.
  • Moved the compilation baseline to the 2024.2 platform line and expanded the verification workflow to selected older and newer IDE builds.
  • Disabled the build tool's optional online update notice to avoid build-time network stalls. This does not disable IDE plugin updates.
  • Kept the existing JMX/JFR workbench feature scope, credential safeguards and evidence limits.

No upper build bound is an installation declaration, not a guarantee that every future IDE API will remain compatible. Build, API verification and GUI acceptance are recorded separately; platform changes can require future plugin updates.

The existing product screenshots were captured with 1.0.0-rc.2 and retain that provenance. This candidate does not claim new screenshots or complete GUI validation across the declared range. ThreadMXBean views cover platform threads, and exported diagnostic data is not automatically redacted.
