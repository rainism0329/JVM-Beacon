1.0.0-rc.2

Second candidate for the first JVM Beacon release, with distribution artwork and English Marketplace onboarding prepared for review.

  • Added the JVM Beacon brand icon for the IDE plugin manager and Marketplace, with a matching dark-theme variant.
  • Prepared real product screenshots and task-based English listing, getting-started and FAQ content.
  • Kept the first-release feature scope: local/remote JMX, connection tabs, on-demand MBean reads and confirmed operations, runtime timelines, platform-thread diagnostics, offline captures, and bounded JFR capture and analysis.
  • Retained the candidate's credential cleanup and JFR filter fixes: unstarted secret-owning tasks are discarded, and automatic polling does not close staged JFR filter controls.

This is a release candidate. Supported inputs, permissions, capture windows and retained-data limits remain explicit. ThreadMXBean views cover platform threads, and exported diagnostic data is not automatically redacted.
